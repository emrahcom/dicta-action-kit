# Harness dicta-action-server 0.1.1

`dicta-action-server` 0.1.1 is released: it cuts a reply text over its limit
instead of sending a stop. Move the harness's pin from `v0.1.0` to `v0.1.1`
(`harness.md`, The check), and update its `package-lock.json` with it.

The harness's guides name no reply text limits, so they do not change.

Check: `npm run check` in the harness and `npm run test:harness` in the kit
pass.
