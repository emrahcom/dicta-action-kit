# LLM check

Add the LLM check, as `specs/llm-check.md` describes. It changes no other repo.

- `playwright.llm.config.ts` for `e2e/llm/`, and `npm run test:llm`: the same
  site and setup as the end-to-end check; the server with the planner from
  `PLANNER`, `claude` by default, and that planner's variables passed through.
  Chromium only, since the check is about the planner, not the browsers. One
  test at a time, with time for several rounds. The server's log also goes to a
  file, so each case reads its own rounds' log lines. The end-to-end config
  leaves `e2e/llm/` out.
- The tests are skipped when the planner's key is missing (Running).
- The cases of the spec (Cases), each as data: the request, the expected change
  in the tasks, how the request ends, and where needed the confirmation text,
  Continue or Cancel, an answer to a question, the page it ends on and the
  words its done text holds. One runner checks every case the same way: all
  tasks before and after, the history, the confirmation, the page.
- `test-results/llm.json` and a printed table (Running), with the reply and the
  history of each failed case.
- One run with the defaults, reported with its table and cost; not committed.
- `README.md` and `CLAUDE.md`: how to run it, what it needs and that it costs
  money.
