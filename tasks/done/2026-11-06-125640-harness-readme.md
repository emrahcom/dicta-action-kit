# Harness README

Give `dicta-action-harness` a README and a license, as `specs/harness.md`
(Contents) describes.

- `README.md`: what the harness is, in a few lines; forking it and making a
  branch for each site, with the commands; opening the agent in the folder; and
  `docs/getting-started.md` as the place to start reading. It does not repeat
  the guides.
- `LICENSE`: the Apache-2.0 text, the same file as in `dicta-action-js`.
