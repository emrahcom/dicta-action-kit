# Harness dicta-action-js 0.1.3

`dicta-action-js` 0.1.3 is released: the buttons of the element go under the
text, in a new `buttons` part. Move the harness's pin of it from 0.1.2 to 0.1.3
(`harness.md`, The check), and update its `package-lock.json` with it.

The harness's guides name no CSS parts, so they do not change.

Check: `npm run check` in the harness and `npm run test:harness` in the kit
pass.
