# Clear values

Let the reference module clear a task's due date or assignee, as `specs/e2e.md`
(Reference module) and `specs/llm-check.md` (Cases) describe, and teach the
same in the harness, as `specs/harness.md` (What it teaches) describes.

- `e2e/module/`: in `tasks.update`, `due` and `assignee` have the type
  `["string", "null"]`, and their descriptions say that `null` clears them. In
  the outputs, the fields that can be empty have the same type list instead of
  "or null" in their descriptions.
- `e2e/llm/cases.ts`: "remove a due date" is no longer expected to fail.
- `dicta-action-harness/docs/writing-capabilities.md`: the section "Clearing a
  value is not possible yet" becomes one on values that can be cleared: the
  type list, the three cases in `run` (left out, `null`, a value), the same
  list in outputs, and a request that clears each such value when trying the
  module. `AGENTS.md` step 5 names that request.
- The end-to-end check, and the LLM check with the defaults, reported: "remove a
  due date" passes.
