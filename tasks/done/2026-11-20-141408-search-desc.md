# Search descriptions

A search's `desc` says how its text matches and what to do when it finds nothing
(`harness.md`, What it teaches, Lists). In LLM check runs, Haiku 5.5 asked the
user when a search for "homepage design" found nothing, where the title is
"Review the design for the new homepage"; with a `desc` that says the text must
appear exactly, to search with one word and to list all on no match, those cases
passed.

- Harness, `docs/writing-capabilities.md`, "Filter long lists": the example's
  `desc` says how its search matches and what to do when it finds nothing, and a
  short paragraph after it says why: the planner cannot see how your search
  works, and a phrase that does not match exactly finds nothing.
- Kit, `e2e/module/teamboard.ts`, the reference module: the `desc` of
  `tasks.list` is "Lists the tasks, at most N. A search finds only titles that
  contain its exact text, so search with one distinctive word; when it finds
  nothing, list all tasks." with N from its constant.

Check: Prettier `--check` on the harness Markdown from the kit, `npm run check`
in the harness, and `npm run check`, `npm run lint`, `npm run test:e2e` and
`npm run test:harness` in the kit pass.
