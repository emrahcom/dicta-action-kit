# End-to-end check

Add the end-to-end check with its reference module, as `specs/e2e.md`
describes. It changes no other repo.

- Tooling, as in `dicta-example-site`: `package.json` with Node.js 24,
  TypeScript, Prettier, oxlint and Playwright (Chromium, Firefox and WebKit);
  `jose` to sign the test tokens. Scripts: `check`, `format`, `lint`, `build`
  for the module and `test:e2e`. The verification commands go into `CLAUDE.md`.
- The reference module in `e2e/module/` (Reference module): the Teamboard
  capabilities and `state`, built with `tsc`.
- The setup (Setup): Playwright starts the example site and
  `dicta-action-server` from the sibling folders; each page gets
  `dicta-action-js`, the module and the element from the site's origin;
  `getToken` gives an expired token first; the store is reset before each test.
- The tests in `e2e/` (Tests).
- A short `README.md`: what the check is, what it needs (the sibling repos
  installed, `dicta-action-js` built) and how to run it.
