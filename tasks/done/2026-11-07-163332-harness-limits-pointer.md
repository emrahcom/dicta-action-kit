# Harness limits pointer

`docs/writing-capabilities.md` in the harness sends readers to
`contract-plan.md` for the limits, but only a plan's limits are there. Point to
both, as `harness.md` (What it teaches) does: `contract-plan.md` for plans,
confirmations and the limits of a plan, and `contract-protocol.md` (Limits) for
the limits of the state, the context and the outputs.

Check: `npm run check` in the harness passes.
