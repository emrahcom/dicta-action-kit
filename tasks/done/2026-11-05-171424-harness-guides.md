# Harness guides

Give `dicta-action-harness` its guides and workflow, as `specs/harness.md`
(Contents, What it teaches) describes. The check command comes in a later task,
once `dicta-action-js` and `dicta-action-server` export what it needs.

- `docs/` with the guides for getting started, writing capabilities and adding
  dicta to the site. The guide for checking the module comes with the check
  command.
- `AGENTS.md`: the workflow, pointing to the guides. Until the check exists, its
  check step says the check is not written yet.
- No Teamboard code in the guides' examples: a user's agent might copy it. The
  examples use a made-up site.
