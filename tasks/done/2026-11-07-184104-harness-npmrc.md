# Harness npmrc

Add `.npmrc` with `allow-git=root` to the harness, as `harness.md` (Contents)
says. npm 12 fetches no git dependencies by default, so `npm install` fails on
the harness's `dicta-action-server` and `dicta-example-site`.

Check: in a fresh clone, `npm install` with npm 12 and with npm 11 installs
both, and `npm run check` passes; `npm run test:harness` in the kit passes.
